# 홈페이지 관리자 사용법 (고객용)

## 들어가기

주소: `https://dopaminroom.kr/admin/`
아이디와 비밀번호는 따로 전달드립니다.

> 비밀번호는 다른 사람과 공유하지 마세요. 바꾸고 싶으시면 말씀해 주세요.

## 기본 사용법

1. 왼쪽 위 메뉴에서 바꾸고 싶은 항목을 고릅니다.
2. 내용을 수정하고 **저장**을 누릅니다.
3. **1~2분 뒤** 홈페이지에 반영됩니다. 바로 바뀌지 않아도 정상입니다.
4. 홈페이지에서 확인할 때 화면이 그대로면 새로고침(휴대폰은 화면을 아래로 당기기) 하세요.

## 메뉴 설명

| 메뉴 | 바꿀 수 있는 것 |
|---|---|
| **기본 정보** | 업소명, 전화번호, 카카오톡 링크, 주소, 영업시간, 소개 문구 |
| **가격** | 주대 등급별 금액, TC, RT, 가격 안내 문구 |
| **룸** | 룸 이름, 수용 인원, 설명 |
| **강점** | 홈페이지 상단의 3가지 강점 |
| **이용 절차** | 문의부터 방문까지의 단계 |
| **시설** | 시설 목록 (한 줄에 하나씩) |
| **이벤트** | 이벤트 · 특별 서비스 |
| **FAQ** | 자주 묻는 질문과 답변 |
| **사진** | 사진 올리기, 순서 바꾸기, 삭제 |
| **백업** | 지금 내용을 파일로 내려받기 |

## 자주 쓰는 작업

### 전화번호 바꾸기
기본 정보 → 예약 전화번호 → 저장

### 가격 바꾸기
가격 → 금액 입력 → 저장
- `150,000원` 처럼 입력해도 되고 `150000` 으로 적어도 됩니다.
- **0으로 두면 홈페이지에 "문의"로 표시**됩니다.
- 등급을 없애려면 등급 이름을 지우고 저장하세요.
- 등급을 추가하려면 맨 아래 "새 등급 추가" 칸에 입력하세요.

### 카카오톡 버튼 넣기
기본 정보 → 카카오톡 링크에 오픈채팅 주소 입력 → 저장
- 비워두면 카톡 버튼이 사라집니다.

### 사진 올리기
사진 → 파일 선택(여러 장 가능) → 올리기
- 순서 숫자가 작을수록 앞에 나옵니다.
- 사진을 바꾼 뒤 "순서·설명 저장"을 누르면 정리됩니다.

### 항목 추가·삭제 (룸, FAQ 등)
- 추가: 맨 아래 빈 칸에 입력하고 저장
- 삭제: 그 항목의 내용을 **모두 지우고** 저장

## 주의사항

- **가격은 실제 금액과 맞게 관리해 주세요.** 홈페이지 금액이 실제와 다르면 문제가 될 수 있습니다.
- 큰 수정을 하기 전에 **백업** 메뉴에서 파일을 먼저 받아두시면 안전합니다.
- 저장했는데 홈페이지가 안 바뀌면 2~3분 기다린 뒤 다시 확인해 주세요. 그래도 그대로면 연락 주세요.
