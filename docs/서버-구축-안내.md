# AWS 서버 구축 안내

도파민 홈페이지 + 관리자 페이지를 AWS EC2 한 대에 올리는 순서.

## 1. EC2 생성

| 항목 | 값 |
|---|---|
| OS | Ubuntu 24.04 LTS |
| 사양 | t4g.small (arm64) 또는 t3.small 이상 |
| 디스크 | 20GB 이상 |
| 보안 그룹 | 22(내 IP), 80(0.0.0.0/0), 443(0.0.0.0/0) |
| 탄력적 IP | 할당 권장 (재부팅해도 IP 가 바뀌지 않음) |

80 포트가 막혀 있으면 인증서 발급이 실패한다.

## 2. 서버 준비

```bash
sudo apt-get update
sudo apt-get install -y git
# Docker 설치
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
sudo usermod -aG docker $USER
```

`usermod` 적용을 위해 재접속한다.

## 3. 코드 받기 + 설정

```bash
git clone https://github.com/byoungguk/dopaminroom.git
cd dopaminroom
cp .env.example .env
nano .env
```

`.env` 에서 반드시 바꿀 값:

- `BASE_URL` — 도메인 연결 전에는 `http://<서버IP>/`
- `ADMIN_PASSWORD` — 고객에게 전달할 관리자 비밀번호
- `ADMIN_SECRET_KEY` — `openssl rand -hex 32` 결과값

## 4. 첫 배포

```bash
./scripts/deploy.sh
```

- 사이트: `http://<서버IP>/`
- 관리자: `http://<서버IP>/admin/`

## 5. 도메인 연결 + https

메일플러그 DNS 에서 A 레코드를 서버 IP 로 바꾼 뒤:

```bash
./scripts/init-cert.sh --dry-run   # 먼저 검증
./scripts/init-cert.sh             # 실제 발급
```

발급 후 `.env` 의 `BASE_URL` 을 `https://dopaminroom.kr/` 로 바꾸고 다시 배포한다.

```bash
./scripts/deploy.sh
```

## 6. 자동 반영 등록

관리자 페이지에서 내용을 바꾸면 `.admin/rebuild.request` 파일이 생긴다.
이 파일을 감시해 사이트를 다시 빌드하는 스크립트를 상주시킨다.

```bash
sudo tee /etc/systemd/system/dopamin-watch.service > /dev/null <<EOF
[Unit]
Description=dopaminroom rebuild watcher
After=docker.service

[Service]
Type=simple
User=$USER
WorkingDirectory=$HOME/dopaminroom
ExecStart=$HOME/dopaminroom/scripts/watch-changes.sh
Restart=always

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now dopamin-watch
sudo systemctl status dopamin-watch
```

## 7. 점검 명령

```bash
docker compose ps                  # 컨테이너 상태
docker compose logs -f nginx       # 접속 로그
docker compose logs -f admin       # 관리자 로그
journalctl -u dopamin-watch -f     # 자동 반영 로그
cat .admin/last-build.txt          # 최근 반영 시각
```

## 구조

```
관리자 페이지(Flask) --수정--> content/site.json, public/images/gallery/
                                      |
                        .admin/rebuild.request 생성
                                      |
         watch-changes.sh (호스트) --> scripts/build.sh --> dist/
                                                              |
                                                     nginx 가 dist 를 서빙
```

관리 컨테이너에 도커 권한을 주지 않기 위해, 빌드는 호스트의 감시 스크립트가 맡는다.
